# MenuBarFeature

The status-bar menu (label + popover) for Polybridge Monitor, built on the
`Coordinator → View → VM → UseCase → ViewRepository` architecture. See `AGENTS.md` for the rules
this package follows and `../../AGENTS.md` for the shared rulebook.

## Build & test

```bash
cd macos/PbFeatures/MenuBarFeature
swift build
swift test
```

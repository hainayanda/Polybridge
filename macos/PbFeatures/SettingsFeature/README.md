# SettingsFeature

The Settings scene (General + Harnesses tabs) for Polybridge Monitor, built on the
`Coordinator → View → VM → UseCase → ViewRepository` architecture. See `AGENTS.md` for the rules
this package follows and `../../AGENTS.md` for the shared rulebook.

## Build & test

```bash
cd macos/PbFeatures/SettingsFeature
swift build
swift test
```
